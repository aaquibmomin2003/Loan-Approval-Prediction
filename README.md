### Exploratory Data Analysis Findings

1. The dataset contained missing values in Gender, Married, Dependents, Self_Employed, LoanAmount, Loan_Amount_Term, and Credit_History columns.

2. Missing categorical values were filled using mode, while numerical values were filled using median.

3. Credit_History was found to be the most influential feature for loan approval. Applicants with good credit history had significantly higher approval rates.

4. Semiurban applicants showed the highest loan approval rate compared to Urban and Rural applicants.

5. Graduates had a slightly higher approval rate than non-graduates.

6. ApplicantIncome showed weak predictive power because approved and rejected applicants had very similar income distributions.

7. Several numerical features contained outliers, especially ApplicantIncome and LoanAmount.

8. The target variable (Loan_Status) appeared moderately imbalanced, with approved loans occurring more frequently than rejected loans.
